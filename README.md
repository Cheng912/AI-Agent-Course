# AI 課程 Agent

## 專案介紹

本專案旨在建立一個 AI 課程客服 Agent，透過自然語言對話的方式，
協助使用者取得課程資訊，並回答與課程相關的問題。

## 問題與需求

當課程數量較多時，使用者可能需要花費大量時間查找課程資訊，
也可能不知道哪些課程符合自己的需求。

因此，本專案希望透過 AI Agent 協助使用者快速取得相關課程資訊，
降低搜尋與理解課程內容所需的時間。

## 專案目標

建立一個能夠理解使用者需求，並根據課程資料提供相關資訊的
AI 課程客服 Agent。

## 使用場景

使用者可以透過本 Agent：

1. 查詢課程基本資訊
2. 詢問課程內容
3. 根據自身需求尋找相關課程
4. 詢問常見的課程相關問題

## 使用範例

**使用者：**

> 我想學習人工智慧，有哪些相關課程？

**Agent：**

> 我可以根據目前提供的課程資料，協助你尋找人工智慧相關課程。
