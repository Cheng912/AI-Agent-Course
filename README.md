# 國立中央大學-AI人工智慧導論-期末AI-Agent專案介紹

## Agent 預期功能介紹

Agent 的核心功能，是將使用者遇到的生活問題轉換成一套清楚、可執行的處理流程。

主要功能包含：

* **情境辨識**
  根據使用者描述的問題，自動判斷目前屬於租屋、報稅、就醫、保險、金融、搬家、政府申辦等哪一類生活情境。

* **需求分析**
  分析目前資訊是否足夠，並主動詢問缺少的重要條件，例如地點、時間、預算、身分條件或事件背景。

* **問題拆解**
  將複雜的生活問題拆解成數個容易理解的小步驟，降低使用者處理問題的負擔。

* **個人化建議**
  根據使用者提供的情況，產生較符合個人需求的處理方式，而不是只提供固定、通用的回答。

* **行動流程產生**
  將資訊整理成明確的處理順序，讓使用者知道「現在該做什麼、接下來做什麼」。

* **待辦清單生成**
  自動建立 Checklist，協助使用者確認哪些事項已完成、哪些事項尚未處理。

* **資訊與資源整合**
  整理相關規定、官方資訊、申請方式、注意事項與其他可信來源，減少使用者自行搜尋大量資料的時間。

* **多步驟任務引導**
  對於需要多個階段才能完成的事情，Agent 可以持續追蹤目前進度，並依照前一步的結果提供下一步建議。

Adulting Agent 的重點不是只回答：

> 「這是什麼？」

而是進一步協助使用者解決：

> **「所以我現在應該怎麼做？」**

因此，本專案的核心概念可以簡化為：

**問題理解 → 情境分析 → 資訊補充 → 任務拆解 → 行動建議 → 完成生活任務**



## 問題與需求

在日常生活中，人們經常會遇到許多「第一次處理」的事情，例如租屋、搬家、報稅、保險、就醫、銀行業務、政府申辦流程等。

雖然網路上通常可以找到相關資訊，但這些資訊往往分散在不同網站，內容也可能過於複雜或缺乏明確步驟。使用者即使找到相關資料，仍可能不知道自己目前最需要做什麼，或應該按照什麼順序處理。

因此，本專案希望解決的核心問題是：

> 當使用者第一次遇到某個生活問題時，如何讓 AI 不只是提供資訊，而是根據實際情境，協助使用者一步一步完成整個處理流程。

---

## 專案目標

本專案目標是開發一個 **Adulting Agent（生活問題處理 AI Agent）**，協助使用者處理日常生活中不熟悉的問題。

Agent 將能夠：

* 理解使用者描述的生活情境
* 判斷處理問題所需要的資訊
* 主動詢問必要的補充條件
* 將複雜問題拆解為明確步驟
* 提供相關知識與可信資訊來源
* 根據使用者情況產生個人化建議
* 產生待辦清單或行動流程
* 協助使用者判斷下一步該做什麼

本專案希望從傳統的 **Question & Answer Chatbot**，進一步發展成能夠協助使用者完成實際生活任務的 **Task-oriented AI Agent**。

---

## 使用場景

Adulting Agent 可以應用於多種日常生活情境，例如：

* 第一次租屋，不知道簽約前應該注意哪些事情
* 第一次搬家，不知道有哪些事項需要提前準備
* 剛開始工作，不了解報稅、勞健保或薪資相關流程
* 身體不舒服，但不知道應該掛哪一科
* 第一次申請政府補助，不清楚資格與申辦流程
* 第一次辦理銀行、信用卡或金融相關業務
* 遇到保險問題，不知道應該準備哪些文件
* 面對合約或重要文件，不知道應該注意哪些條款

未來也可以持續擴充更多生活類型，使 Agent 成為一個可以協助處理各種「人生第一次」問題的生活助手。

## 使用範例

### 使用者

> 我第一次在外面租房子，房東要求我要先付兩個月押金，我現在需要注意什麼？

### Adulting Agent

Agent 會先辨識使用者目前正在處理「租屋」情境，接著根據需要詢問相關資訊，例如租屋地點、契約內容、租金與其他費用等。

接著 Agent 可以協助使用者確認：

1. 租屋契約中的重要條款
2. 押金與租金的付款方式
3. 水電費與其他額外費用
4. 房屋現況與設備檢查
5. 應該保留的契約、收據與照片
6. 是否可能符合租屋補助資格
7. 入住前與入住後需要完成的事項

最後，Agent 可以整理出一份個人化待辦清單，例如：

* 確認租賃契約內容
* 拍攝入住前房屋狀況
* 保存付款證明
* 確認水電費計算方式
* 查詢租屋補助資格
* 完成入住檢查清單

透過這樣的流程，Adulting Agent 不只是回答「租屋要注意什麼」，而是協助使用者將問題轉換成可以實際執行的步驟。
